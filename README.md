# Turn Based Battle Simulator

A turn‑based battle simulator inspired by Pokémon‑style combat mechanics.  
Built in Python with a clean, modular, object‑oriented architecture.

---

## 🎮 Overview

This project simulates classic turn‑based monster battles using simplified mechanics:
- Stats (HP, Attack, Defense, Speed)
- Moves with power + type
- Turn order based on Speed
- Automatic damage calculation
- Team system with active Pokémon switching
- Full battle loop until one team faints

The goal is to create a flexible, extensible battle engine that can grow into:
- A full CLI game  
- A Pokopía‑style custom creature system  
- A GUI or web‑based battle simulator  
- A foundation for more advanced mechanics (type charts, status effects, AI, etc.)

---

## 🧩 Features

### ✔ Core Mechanics
- Object‑oriented Pokémon, Move, Team, and Battle classes  
- Deterministic turn order based on Speed  
- Basic damage formula  
- Automatic faint detection  
- Team victory logic  

### ✔ Clean Architecture
- Each class lives in its own file  
- Easy to extend with new mechanics  
- Beginner‑friendly and readable  

### ✔ Example Battle Included
`main.py` runs a full Charmander vs. Bulbasaur battle out of the box.
